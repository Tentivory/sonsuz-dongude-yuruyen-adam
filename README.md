# Sonsuz Döngüde Yürüyen Adam

Bu repository, insanlık tarihinin en büyük başarılarından biri değildir. Hatta hiçbir şey değildir. Ama işte buradayız.

## Ne Yapıyor?

Bir adam var. Yürüyor. Sonsuza kadar. Nereye gittiğini bilmiyor, umursamıyor da. Ara sıra "Nereye gidiyorum ya?" diye soruyor ama cevap beklemiyor. Çünkü cevap yok.

Bu kod gerçekten çalışır. Sonsuz döngüde "Adam yürüyor..." yazar, biraz bekler, bazen durur, düşünür, sonra yine yürür. Bilgisayarının fanını biraz yorar, o kadar.

## Nasıl Çalıştırılır?

```bash
python yuruyen_adam.py
```

Durdurmak için Ctrl+C. Ya da bilgisayarı kapat. Ya da hayatını sorgula.

## Neden Var?

Çünkü biri sordu "saçma bir repo aç" diye. Ve işte açtık. Anlamı yok. Olması da gerekmiyor. Türkçe olsun yeter.
